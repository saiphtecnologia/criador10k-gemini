# Criador 10K · Máquina de Conteúdo para Gemini

Kit oficial para criar um Gem personalizado do Criador 10K no Gemini.

O Gem foi pensado para desenvolver briefing, headlines, narrativa, copy por slide, fechamento e revisão editorial. A montagem visual continua na Máquina de Conteúdo:

https://maquina.criador10k.com.br

## Como criar

1. Acesse https://gemini.google.com no computador.
2. Abra a barra lateral e entre em **Gems**.
3. Clique em **Novo Gem**.
4. Use o nome **Criador 10K · Máquina de Conteúdo**.
5. Copie todo o conteúdo de `INSTRUCOES-GEM.txt` para o campo de instruções.
6. Em **Conhecimento**, adicione os três arquivos da pasta `conhecimento/`.
7. Teste o Gem na prévia e clique em **Salvar**.

## Arquivos de conhecimento

- `01-metodo-editorial.md`
- `02-modelos-e-densidade.md`
- `03-qualidade-e-revisao.md`

## Exemplos

- "Quero transformar um conteúdo existente em carrossel."
- "Tenho um insight e quero criar uma narrativa."
- "Revise esta copy com o método Criador 10K."

## Compartilhamento

Depois de salvar, use o menu de compartilhamento do Gem para copiar o link e escolher o nível de acesso disponível na sua conta.

Importante: usuários com acesso ao Gem podem visualizar suas instruções e arquivos de conhecimento. Por isso este kit usa apenas a camada editorial necessária ao uso público.
